CyclePeakLookahead

CyclePeakLookahead delays the input signal by a small, user–set lookahead time so that the module can track peaks slightly before they reach the output. The detected peak level (with optional absolute mode and hysteresis) is exposed on a control pin for downstream processing or visualization.

What it does

  • Lookahead: Buffers the input so peaks can be anticipated.
  • Peak tracking: Outputs a smoothed peak value with hysteresis.
  • Absolute mode: Optionally detect peaks on absolute signal level.

Pins

  • Input (Audio In) — Mono audio to be delayed/analyzed.
  • Output (Audio Out) — The lookahead-delayed copy of the input.
  • Lookahead (ms) (Float In) — Delay amount in milliseconds. Typical: 0–30 ms. Default: 0.0.
  • Hysteresis (Float In) — Decay per sample applied to the tracked peak when the signal is falling. Use small values (e.g. 0.0001–0.01). Default: 0.0.
  • Absolute Mode (Int In) — If non-zero, peak detection uses absolute value of the input (rectified). Default: 0 (off).
  • Peak (Float Out) — Current tracked peak value (0..1).

Parameters

Max Lookahead 30 ms (derived internally from sample rate)
Sample Rate Read from host/DAW at runtime

Tips

  • Increase Lookahead (ms) to give more time for downstream processors (e.g. envelope followers or limiters) to react to peaks.
  • Use a small Hysteresis to make the peak meter decay smoothly instead of stepping down instantly.
  • Enable Absolute Mode for symmetrical signals where negative peaks matter as much as positive ones.
